# 📊 Task 15 – Product Count Analysis

## Veda Technology – Data Analytics Internship

This project was completed as part of the Veda Technology Data Analytics Internship – Task 15.

The main objective of this task is to analyze product counts by category, identify the category with the highest number of products, and understand the difference between total product records and unique products.

An interactive dashboard was also created to visualize the analysis.

---

## 🎯 Objective

- Count products by category
- Identify the category with the highest product count
- Find unique products
- Practice COUNTIF and COUNTIFS concepts
- Create product count tables
- Visualize product distribution
- Build an interactive dashboard

---

## 🛠️ Tools & Technologies

- Python
- Pandas
- Plotly
- Matplotlib
- Google Colab
- Excel
- OpenPyXL
- GitHub

---

## 📂 Dataset

The project uses a Superstore-style sales dataset.

The dataset contains product and category information that is used for product count analysis.

---

## 📊 Analysis Performed

### 1. Product Count by Category

Products were grouped according to their category and counted.

### 2. Unique Product Analysis

The number of unique products was calculated using Pandas.

### 3. Top Category

The category having the highest product count was identified.

### 4. COUNTIF

The Excel COUNTIF concept was implemented using Pandas filtering.

### 5. COUNTIFS

The Excel COUNTIFS concept was demonstrated using multiple filtering conditions.
